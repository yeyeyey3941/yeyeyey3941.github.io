## 🌟 주요 프로젝트

### 1. Datepeek : 지역기반 데이트 스팟 공유
- **설명**: 직접 데이트 코스를 만들고 공유하며, 다른 사람들의 추천 코스를 손쉽게 찾아볼 수 있는 플랫폼 개발 프로젝트
- **기술 스택**: Node.js, Express, Mysql, React
- **특징**: passport.js 를 통한 인증 시스템 구현 프로젝트, AWS EC2+ALB 를 활용한 배포 경험(현재는 종료)
- **링크**: [GitHub 저장소](https://github.com/yeyeyey3941/Q2_Project_Back)

### 2. Django-tuto : 모놀리틱 아키텍쳐 구현 경험 프로젝트
- **설명**:  모놀리틱 아키텍쳐 구현 시스템 및 모니터링 시스템 구축 경험을 위한 프로젝트
- **기술 스택**: Python, Django, React, Docker-compose, Nginx, ELK, Prometheus, Grafana
- **특징**: 
  1. Docker-compose 를 통해 Django 와 React 를 연동하여 모놀리틱 아키텍쳐 구현 경험 프로젝트
  2. Nginx 를 사용한 리버스 프록시 & static 파일 서빙
  3. ELK+filebeat 와 Django Backend 연동을 통한 로깅 시스템 구축
  4. Prometheus+Grafana 와 Django Backend 연동을 통한 메트릭 수집 및 모니터링 시스템 구축
- **링크**: [GitHub 저장소](https://github.com/yeyeyey3941/django-tuto)
